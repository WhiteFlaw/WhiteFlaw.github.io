# 类型定义
```c
typedef struct { // struct定义结构体(类型),这种结构应当包含两个float类型
    float realpart; // 该部分存储实部;
    float imagepart; // 该部分存储虚部;
}Complex; // typedef 类型 类型名,此处将这种构造体命名为complex
```
## 类型实例化
```c
typedef struct {
    float realpart;
    float imagepart;
}Complex;

```c
Complex a;
a.realpart = 3.0f;
a.imagepart = 4.0f;
// 或
Complex b = {1.5f, -2.5f};   // 声明并初始化，表示 1.5 - 2.5i
```
## 抽象数据类型定义
```c
Void assign(Complex*A, float real, float image) { // 需求:complex类型形参A, float类型实部, float类型虚部
    A -> realpart = real; // 实参real赋值给实参A中的realPart
    A -> imagepart = image; // 实参image赋值给实参A中的imagePart
}
```

# 时间复杂度
算法中重复执行次数最多的语句主导算法的时间复杂度.
为什么要"忽略"少数几次? 因为时间复杂度关心的是当n越来越大时，耗时的增长趋势.
在某一语句的执行次数无限大的时候,其他语句对时间复杂度的贡献都可以忽略.
```c
void exam(float x[][n], int m, int n) { //传入二维数组x,n是必要的, 没有列数会影响寻址
    for(int i = 0; i < m; i++) {
        for(int j = 0; j < n; j++) {
            sum[i] += x[i][j]; // 执行次数最多的语句, 执行了nm次
        }
    }
}
```
## 分析时间复杂度的方法
找出频度(执行次数)最大的语句作为基本语句.
计算基本语句的频度得到问题规模n的某个函数f(n), 语句频度就是这语句执行了多少次.
本质是利用未知数字n来表示某语句的执行次数.
