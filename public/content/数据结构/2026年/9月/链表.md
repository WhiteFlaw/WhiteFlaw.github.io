# 链表
## 链表的定义
一种在内存中不连续存放数据元素，把每个元素存放在独立“结点”里，结点之间通过指针连接起来的存储结构。
## 链表的结构特点
（这就像一团带有节点的麻绳，胡乱缠在一起，但是顺着绳子找又能准确找到每一个节点）
非连续内存：在这种结构中逻辑上相邻的元素，物理上不一定相邻。
不支持随机访问：不能通过下标直接访问元素，必须从头开始逐个查找。
增删改简单：插入和删除通常只需要修改指针，不需要移动大量元素。
## 常见类型
| 类型 | 特点 |
|---|---|
| 单链表 | 每个结点一个指针，指向后继结点 |
| 双链表 | 每个结点两个指针，分别指向前驱和后继 |
| 循环链表 | 尾结点指针指向头结点，形成环 |
| 静态链表 | 用数组模拟指针，适合不支持动态内存的语言 |
## 指针
节点在内存中分为两部分：
+---------+---------+
|  数据域  |  指针域  |
+---------+---------+
数据域：存放真正的数据，比如 10、"abc"。
指针域：存放另一个结点的地址，指向另一个结点。
举例
| 结点地址 | 数据域 | 指针域（next） |
|---|---|---|
| 0010 | A | 0019 |
| 0019 | B | 0025 |
| 0025 | C | 0030 |
| 0030 | D | NULL |
head → A(0010) → B(0019) → C(0025) → C(0030) → NULL

## 单链表
通过先定义节点对象再建立节点间联系的面向对象方式来构建一个单链表.
```C#
public class Node<T> // 定义节点类
{
    // 数据域
    public T Data { get; set; }
    // 指针域：指向下一个结点
    public Node<T>? Next { get; set; }
    public Node(T data)
    {
        Data = data;
        Next = null;
    }
}
```
```C#
public class SingleLinkedList<T> // 定义单链表
{
    // 头指针：指向第一个结点
    private Node<T>? head; // 声明私有字段 类型Node<T> 字段名head

    // 判断链表是否为空
    public bool IsEmpty => head == null;

    // 头插方法：在链表头部插入
    public void AddFirst(T data)
    {
        var newNode = new Node<T>(data);
        newNode.Next = head;
        head = newNode;
    }

    // 尾插方法：在链表尾部插入
    public void AddLast(T data)
    {
        var newNode = new Node<T>(data);

        if (head == null)
        {
            head = newNode;
            return;
        }

        var current = head;
        while (current.Next != null)
        {
            current = current.Next;
        }

        current.Next = newNode;
    }

    // 遍历打印方法
    public void Print()
    {
        var current = head;
        while (current != null)
        {
            Console.Write(current.Data + " -> ");
            current = current.Next;
        }
        Console.WriteLine("null");
    }

     public bool Remove(T data)
    {

        // 要删除的结点恰好是头结点
        if (EqualityComparer<T>.Default.Equals(head.Data, data))
        {
            head = head.Next;   // 头指针后移，原头结点被移除（由GC回收）
            return true;
        }

        // 要删除的结点在中间或尾部，需要前驱指针
        var current = head;
        while (current.Next != null)
        {
            if (EqualityComparer<T>.Default.Equals(current.Next.Data, data))
            {
                // 跳过 current.Next，即删除它
                current.Next = current.Next.Next;
                return true;
            }
            current = current.Next;
        }

        // 遍历结束，未找到目标数据
        return false;
    }
}
```

## 双向链表
一种在每个元素数据域前后均有指针域存在的链表, PREV指针的存在使得从下风向向上风向的查找得以实现.
+----------+---------+----------+
|  指针域  |  数据域  |  指针域  |
+----------+---------+----------+

这里依然是基于联系节点对象实现一个双向链表.
```C#
// 双向链表节点类
public class DoublyNode<T>
{
    public T Data { get; set; }
    public DoublyNode<T>? Prev { get; set; }  // 前驱指针
    public DoublyNode<T>? Next { get; set; }  // 后继指针

    public DoublyNode(T data)
    {
        Data = data;
        Prev = null;
        Next = null;
    }
}

// 双向链表类
public class DoublyLinkedList<T>
{
    // 该结构应当具备私有的基于实例化DoublyNode类得到的head、tail对象
    private DoublyNode<T>? head;
    private DoublyNode<T>? tail;

    // 链表元素个数
    private int count;

    // 属性
    public int Count => count;
    public bool IsEmpty => head == null;

    public DoublyLinkedList() // 构造函数
    {
        head = null;
        tail = null;
        count = 0;
    }

    /// 头插法
    public void AddFirst(T data)
    {
        var newNode = new DoublyNode<T>(data);

        if (head == null)          // 空链表
        {
            head = newNode;
            tail = newNode;
        }
        else
        {
            newNode.Next = head;
            head.Prev = newNode;
            head = newNode;
        }
        count++;
    }

    /// 尾插法
    public void AddLast(T data)
    {
        var newNode = new DoublyNode<T>(data);

        if (tail == null)          // 空链表
        {
            head = newNode;
            tail = newNode;
        }
        else
        {
            tail.Next = newNode;
            newNode.Prev = tail;
            tail = newNode;
        }
        count++;
    }

    /// 在指定索引处插入节点
    public void InsertAt(int index, T data)
    {
        if (index < 0 || index > count)
            throw new ArgumentOutOfRangeException(nameof(index), "索引超出范围");
        // 头插
        if (index == 0)
        {
            AddFirst(data);
            return;
        }
        // 尾插
        if (index == count)
        {
            AddLast(data);
            return;
        }
        // 中间插入：找到原 index 位置的节点
        var current = GetNodeAt(index);
        var newNode = new DoublyNode<T>(data);

        // 在 current 之前插入 newNode
        newNode.Prev = current!.Prev;
        newNode.Next = current;
        current.Prev!.Next = newNode;
        current.Prev = newNode;

        count++;
    }

    /// 删除指定索引处的节点
    public bool RemoveAt(int index)
    {
        if (index < 0 || index >= count)
            return false;

        var node = GetNodeAt(index);
        RemoveNode(node!);
        return true;
    }

    /// 删除头节点
    public bool RemoveFirst()
    {
        if (head == null) return false;
        RemoveNode(head);
        return true;
    }

    /// 删除尾节点
    public bool RemoveLast()
    {
        if (tail == null) return false;
        RemoveNode(tail);
        return true;
    }

    /// 清空链表
    public void Clear()
    {
        head = null;
        tail = null;
        count = 0;
    }

    /// 修改指定索引处节点的数据
    public bool UpdateAt(int index, T newData)
    {
        var node = GetNodeAt(index);
        if (node == null) return false;

        node.Data = newData;
        return true;
    }

    /// 根据索引获取节点数据
    public T? GetAt(int index)
    {
        var node = GetNodeAt(index);
        return node == null ? default : node.Data;
    }

    /// 打印
    public void PrintForward()
    {
        var current = head;
        var sb = new StringBuilder();
        while (current != null)
        {
            sb.Append(current.Data);
            sb.Append(" <-> ");
            current = current.Next;
        }
        sb.Append("null");
        Console.WriteLine(sb.ToString());
    }
```

# 循环链表
循环链表是单链表/双链表的附加条件, 单向/双向循环链表都是成立的.

对于单链表来讲, 循环即链表尾next指针不再指向NULL, 而是回头指向HEAD. 这会存在一个问题: 遍历将陷入无限循环.
那么我们将不再能使用对正常单链表的遍历方法, 而是使遍历在HEAD前停止, 如此可以遍历到全部元素而不重复.

对于双向循环链表, 其内部与双向链表并无二致, 差别在首尾: 尾部NEXT指向HEAD的PREV, 而HEAD的PREV又指向尾部.
