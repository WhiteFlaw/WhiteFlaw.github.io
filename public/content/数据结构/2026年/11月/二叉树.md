## 二叉树的定义

- `n ≥ 0` 个结点的集合, 空树或非空树。
- 非空树: 有且仅有一个根; 其余结点分成**互不相交**的左右子树, 且本身也是二叉树。
- **与树的区别**: ① 每个结点至多两棵子树; ② 子树**有左右之分**, 不能颠倒。

**5 种基本形态**: 空树、只有根、右子树空、左子树空、左右都非空。

## 二叉树的性质

| 性质 | 内容 | 备注 |
|---|---|---|
| 1 | 第 `i` 层至多 `2^(i-1)` 个结点 | 至少 1 个 |
| 2 | 深度 `k` 至多 `2^k - 1` 个结点 | 至少 k 个 |
| 3 | `n0 = n2 + 1` | 叶子数 = 度为 2 的结点数 + 1 |
| 4 | 完全二叉树深度 `= ⌊log₂n⌋ + 1` | |

**满二叉树**: 深度 `k`, 结点数 `2^k - 1` (每层排满)。
**完全二叉树**: 与同深度满二叉树的 `1~n` 号结点一一对应。

- 叶子只出现在最下两层;
- 右分支子孙最大层次为 `l`, 则左分支必为 `l` 或 `l+1`;
- 路径长度最短, 但**路径最短的不一定是完全二叉树**。

**性质 5 (编号规律)**: 结点 `i` 的双亲 `⌊i/2⌋`, 左孩子 `2i`, 右孩子 `2i+1` (`i=1` 是根, 无双亲)。

## 二叉树的存储结构

**顺序存储**
- 完全二叉树: 按层序存, 编号 `i` 存在下标 `i-1`;
- 一般二叉树: 补 0 占位, **单支树极度浪费**, 要为完全二叉树留同样空间。

**链式存储**
```c++
typedef struct BiTNode {
    TElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```
- `n` 个结点的二叉链表有 **`n + 1` 个空指针域** (线索化的来源);
- 增加 `parent` 域即三叉链表, 便于找双亲。

## 建树

```c++
using namespace std;

typedef int TElemType;

struct BiTNode { // 结构体BiTNode
    TElemType data;
    BiTNode* lchild, * rchild;
};
typedef BiTNode* BiTree; // 基于链表实现的树结构本质是指向链表首元节点的指针, 所以BiTNode的指针(*)别称为BiTree;

void CreateBiTree(BiTree& T) { // 参数类型:BiTree的引用, 该参数决定树的节点的地址
    int x;
    cin >> x; // cin 是一个输入流对象, 等待键盘输入，然后把输入内容按 x 的类型转换后放进 x
    if (x == -1) T = NULL;
    else {
        T = new BiTNode; // new一个节点存入节点地址
        T->data = x; // x赋值给T地址中的data
        CreateBiTree(T->lchild);
        CreateBiTree(T->rchild);
    }
}

// 先序：根 左 右
void PreOrder(BiTree T) {
    if (!T) return;
    cout << T->data << " ";
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}

// 中序：左 根 右
void InOrder(BiTree T) {
    if (!T) return;
    InOrder(T->lchild);
    cout << T->data << " ";
    InOrder(T->rchild);
}

// 后序：左 右 根
void PostOrder(BiTree T) {
    if (!T) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    cout << T->data << " ";
}

int main() {
    BiTree T = NULL;
    CreateBiTree(T);          // 输入：1 2 4 -1 -1 5 -1 -1 3 -1 -1

    cout << "先序: "; PreOrder(T);  cout << endl;
    cout << "中序: "; InOrder(T);   cout << endl;
    cout << "后序: "; PostOrder(T); cout << endl;
    return 0;
}
// 运行程序: Ctrl + F5 或调试 >“开始执行(不调试)”菜单
// 调试程序: F5 或调试 >“开始调试”菜单
```

## 遍历树

**定义**: 按某条路径巡访每个结点, 每个结点**只访问一次**。实质是把非线性结构**线性化**。

**三种遍历只看根在哪**: 先序 = 根左右, 中序 = 左根右, 后序 = 左右根。三种只是访问根的时机不同, 递归结构完全一样。

**例**: `a + b * (c - d) - e / f`

| 遍历 | 序列 | 表达式 |
|---|---|---|
| 先序 | `- + a * b - c d / e f` | 前缀 (波兰式) |
| 中序 | `a + b * c - d - e / f` | 中缀 |
| 后序 | `a b c d - * + e f / -` | 后缀 (逆波兰式) |

**非递归中序** (用栈模拟): 一路向左压栈 → 到底弹一个访问 → 转向右子树。`p` 空且栈空时结束。

**由遍历序列确定二叉树**

| 组合 | 能否唯一确定 |
|---|---|
| 先序 + 中序 | **能** |
| 后序 + 中序 | **能** |
| 先序 + 后序 | **不能** |

- 先序首结点 / 后序末结点 = 根, 再到中序里按根的位置切出左右子树;
- 先序 + 后序不行, 因为分不清某个孩子是左还是右。

## 线索二叉树

**动机**: `n` 个结点有 `n + 1` 个空指针域, 浪费; 且遍历时才能知道前驱后继。把它们存进空域就是线索。

> **前驱/后继不是链表里的指针域**, 而是线索化时按某种遍历产生的线性序列中, 某个值的前一个和后一个。可把该序列看作一个链表: 左指前驱, 右指后继。

**结点结构与标志**

```c++
typedef struct BiThrNode {
    TElemType data;
    struct BiThrNode *lchild, *rchild;
    int LTag, RTag;   // 0 = 指向孩子, 1 = 指向前驱/后继
} BiThrNode, *BiThrTree;
```

- `LTag = 0` 指左孩子, `LTag = 1` 指前驱;
- `RTag = 0` 指右孩子, `RTag = 1` 指后继。

**线索化 (以中序为例)**: 本质是**在遍历过程中把空指针改成线索**。用 `pre` 记刚访问过的结点, `p` 指向当前结点:

1. 左子树递归线索化;
2. `p` 左孩子空 → 加左线索, `LTag = 1`, `lchild = pre`;
3. `pre` 右孩子空 → 加右线索, `RTag = 1`, `rchild = p`;
4. `pre = p`;
5. 右子树递归线索化。

**关键**: 左线索在访问 `p` 时建, 右线索要等到访问 `p` 的后继时才补 —— 所以第 3 步检查的是 `pre->rchild`, 不是 `p->rchild`。
