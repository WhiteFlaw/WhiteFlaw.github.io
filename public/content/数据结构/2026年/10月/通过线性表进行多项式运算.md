# 通过线性表表示多项式
利用链表节点的值域、顺序表的下标与值的对应关系来存储对多项式采样得到的关键样本，从而利用线性表在一定程度上表示原多项式。
目的是将现实多项式程序化, 参与计算机运算.

## 采样关键信息
需要采样的关键信息：每项的指数（次幂）、系数

示例：`A(x) = 7 + 3x + 9x^8 + 5x^10`;
采样结果用表格可以表示为:
| 项序号 | 指数 | 系数 |
|---|---|---|
| 1 | 0 | 7 |
| 2 | 1 | 3 |
| 3 | 8 | 9 |
| 4 | 10 | 5 |

## 稀疏多项式与稠密多项式
稠密或稀疏取决于多项式任意相邻两项指数之差, 若大于1则为稀疏.
该多项式用数组这种需要连续内存空间的存储结构表示的话, 两个有效元素之间将存在大量零值以使数组下标与指数值对应.

## 用数组表示多项式
存储方式`array[指数] = 系数`;
以上例子`A(x) = 7 + 3x + 9x^8 + 5x^10`便是一个稀疏多项式, 2、3项和3、4项的指数差都大于1, 若用数组表示该多项式:
```C#
int[] samplePolynomialRes = { 7, 3, 0, 0, 0, 0, 0, 0, 9, 0, 5 };
```
数组内的有效元素将稀疏分布.
对于`P(x) = 10 + 5x - 4x^2 + 3x^3 + 2x^4`这种稠密多项式, 适合用数组表示:
```C#
int[] samplePolynomialRes = { 10, 5, -4, 3, 2 };
```
可见从内存占用方面考虑, 占用连续内存的数组更加适合存储稠密多项式, 而链表在存储结构上可以利用分散内存保持自身, 适合存储稀疏多项式.

## 用链表表示多项式
稀疏多项式`A(x) = 7 + 3x + 9x^8 + 5x^10`采样后用单链表表示
存储方式
| value | next | value | next | value | next | value | next | value | next |
|---|---|---|---|---|---|---|---|---|---|
| -1 | → | {7, 0} | → | {3, 1} | → | {9, 8} | → | {5, 10} | → |

# 线性表实现多项式加法运算
两多项式相加: 所有指数相同的项的系数相加, 若系数相加结果等于0, 则该项舍弃.
`A(x) = 7 + 3x + 9x^8 + 5x^10`与`P(x) = 8x + 22x^7 - 9x^8`相加, 结果为`R(x) = 7 + 11x + 5x^10`;
将算完的结果式用表存储即可.

# 程序创建多项式

## 创建链表节点
```C#
// 定义多项式节点结构体 PNode
typedef struct PNode
{
    float coef;
    int expn;
    struct PNode *next; // 在struct PNode这个结构体里面，有一个成员叫next，它的类型是struct PNode *
} PNode, *Polynomial;
```
这其实是一种固定的语法格式, typedef是别名的意思, 这个语句实际上在为类型`struct PNode`定义一系列别名:
`typedef ??? 别名1, 别名2, ...;`
PNode, Polynomial这两个其实是struct PNode的两个别名, Polynomial是一个指针类型的别名, 它的类型是struct PNode *即"struct PNode指针".

## 基于链表创建多项式
```C#
// 算法描述：输入 n 项的系数和指数，建立表示多项式的有序链表 P
void CreatePolyn(Polynomial &P, int n)
{

    P = new PNode; // 先建立一个带头结点的单链表P
    P->next = NULL; //这个链表现在只有头节点

    // 循环 n 次，依次输入 n 个非零项
    for (int i = 1; i <= n; ++i)
    {
        PNode *s = new PNode; // 生成新结点s, 类型为"PNode指针", 赋值一个PNode对象给它

        // cin标准输入流对象，一般代表键盘输入
        cin >> s->coef;  // 从键盘读取值，赋给节点s, 指向coef系数
        cin >> s->expn;  // 从键盘读取值，赋给节点s, 指向expn指数

        // prev为q的前驱，初值为头结点P
        PNode *prev = P; 
        
        // 生成指针变量q, 类型为"PNode指针", 因为值为首元节点(头结点后面第一个实际数据结点)的地址, 所以q也指向首元节点
        PNode *q = P->next;

        // while过程中q值一直变, 直到找到合适位置, q的值会定下来
        // 用while查找合适的位置插入s: 若q的指数大于等于s的指数, 循环退出
        while (q && q->expn < s->expn)
        { // 往后找的话q和它的前驱prev要集体后移
            prev = q;       // prev后移
            q = q->next;   // q后移
        }
        
        // while循环停止后q的指数大于等于s的指数, s需要插入到q和prev之间
        s->next = q;
        prev->next = s;
    }
}
```

# 多项式的相加
我们的思路:
首先明确进入循环, 刚开始会用第n项比较第n项, 直到出现不相等, 需要检查是主干小了还是来源小了, 若主干小了, 主干的项就直接加进和多项式(因为未来的循环中, 来源提供的指数只会更大, 不可能再相等), 若主干大了就把来源加进和多项式(因为未来的循环中, 主干提供的指数只会更大, 不可能再相等)然后继续用主干的这个节点比较来源的下一个节点;如果正好相等就系数相加再加入和多项式.每一步结束之后更新指针指向.

问题: 但这样的循环, 是不是只有当两多项式指数相同项在同一位置时才能正确工作? 比如3次幂在多项式A的第三项, 而B的3次幂在第一项, 循环一开始不就用A的1次幂去比较B的3次幂然后判定无法相加?
提出这个问题说明忽略了多项式的一个特性: 这个算法依赖于链表是有序的。如果多项式是无序的，这个算法确实会出错。但在数据结构课程中，多项式链表通常默认按指数有序（且通常是升序）
```C++
void AddPolyn(Polynomial &Pa, Polynomial &Pb)
{ // 传入两个链表的首节点以访问两链表, 注意首节点是无数据的节点, 从首元节点才有数据;
    p1 = Pa->next; p2 = Pb->next; // p1和p2初始时分别指向Pa和Pb的首元结点
    p3 = Pa;                      // 以pa作为主干链表, 存储和多项式
    
    while (p1 && p2)              // 主干和来源链表均非空
    {
        if (p1->expn == p2->expn) // 若本轮中主干节点和来源节点的指数相等
        {
            sum = p1->coef + p2->coef; // sum保存两项的系数和
            if (sum != 0) {            // 系数和不为0
                p1->coef = sum;        // 修改主干当前结点的系数值为两项系数的和
                p3->next = p1;         // 将修改后的主干当前结点链接在p3之后
                p3 = p1;               // 更新p3, 准备下一轮循环
                p1 = p1->next;         // p1指向后一项
            } else {                   // 系数和为0
                r = p1; p1 = p1->next; delete r; // 这一项互相抵消不存在了, 删除主干数组当前结点，p1指向后一项
            }
            r = p2; p2 = p2->next; delete r; // 删除来源数组当前结点，p2指向后一项
        }
        else if (p1->expn < p2->expn) // 主干结点指数值小于来源结点指数值, 主干结点直接加进和多项式
        {
            p3->next = p1;            // 将p1链接在p3之后
            p3 = p1;                  // p3指向p1
            p1 = p1->next;            // p1指向后一项
        }
        else                          // 主干结点指数值大来源结点指数值, 来源结点直接加进和多项式
        {
            p3->next = p2;            // 将p2链接在p3之后
            p3 = p2;                  // p3指向p2
            p2 = p2->next;            // p2指向后一项
        }
    }
    
    p3->next = p1 ? p1 : p2;          // 插入非空多项式的剩余段
    delete Pb;                        // 释放Pb的头结点
}
```
