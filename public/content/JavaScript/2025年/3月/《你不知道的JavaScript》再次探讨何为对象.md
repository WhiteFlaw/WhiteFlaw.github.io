简单基本类型本身不是对象.

null被当作对象类型是语言本身的bug， type of null为object，这是由于对象在底层表示为二进制，在JavaScript二进制前3位都为0会被判断为object类型，null全部的位都是0,所以被判Object.

我必须强调,我曾信服的"JavaScript中万物皆是对象”显然是错误的.

"函数是对象的一种子类型，技术角度来说就是"可调用的对象"，函数本质上和普通对象一样, 所以可以像操作其他对象一样操作函数.

函数能作为参数，也是由于其对象的本质.

数组也是对象的一种子类型.

Number、String、Error等都是内置构造函数,也是内置对象.

用字面量创建number,string之类时，不使用专用于创建该类型的构造函数构造，所以得到的值不具备该类型本该有的方法仅是一个字面意义上的值，它并没有这个类型真正该具备的东西.
比如
```javascript
const str = 'aa';
```
'aa'获取这个字符串字面量的长度/访问某个字符本是做不到的(能做到是因为其他原因，等下就说).
但new string('aa');通过字符串构造函数实例化出一个字符串对象(它的typeof是Object)，字符串方法在原型里，innerHTML出来依旧是字符串而非一个对象.

你可能很心动, 决定以后都要这样构造,但实际上在必要时引擎会自动把字面量转对象(这也是为何我们能直接在字面量上调用方法)，不然我们写个数字都要实例化了.

比如

```javascript
34.192.toFixed(1);
```
引擎会把数值字面量转对象使得方法能够调用.

简单基本类型(null/undefined除外)用字面量方便的声明，并在需要的时候自动转为对象.
而Object, Array, Function, 无论以字面量形式or构造形式构造, 都是对象.
