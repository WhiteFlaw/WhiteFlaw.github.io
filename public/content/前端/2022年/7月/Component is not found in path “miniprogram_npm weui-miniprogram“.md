# 前言

昨晚看了一下, 依赖也都引入了, 路径也没什么问题, 我明明记得收工的时候没有BUG, 但是现在连从github上拉下来的版本都跑不起来了.

# 一、排查错误
看了半天也没看出来是怎么回事...
github上拉下来的代码和本地代码是一样的.

页面也引入了:
```json
"usingComponents": {
  "mp-searchbar": "weui-miniprogram/searchbar/searchbar"
},
```
app.json也挂上了:
```json
"useExtendedLib": {
  "weui": true
}
```
为了尽量排除错误, 我还重构了一下npm, 但是也没用.


---

# 二、解决方法
去查了一下发现以前有人遇到过weui引入后检查不到的情况, 而且是由编辑器引起的, 具体表现为换账号登录, 或者换机器可以解决.

回想了一下以前都是用我的微信账号登录后编辑的, 这次直接用了游客账号登录, 不知道是不是这个原因.

尝试了一下登录后编译, 解决...
